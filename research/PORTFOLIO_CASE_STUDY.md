# Trading-for-You — first project case study

Prepared 11 October 2026. Evidence-backed project presentation; not a trading-performance advertisement.

## Problem and user

A Telegram user needs to inspect a paper trading system, understand its decisions and evaluate whether a strategy has evidence beyond attractive backtests. The project targets transparent research and virtual account tracking with documented risk and data constraints.

## Demonstrable work

The deployed worker provides owner-controlled Telegram reporting and virtual market observations. Separate hypothetical accounts support matched strategy and cost comparisons. The research branch adds a reproducible SPY retrospective campaign, paired uncertainty checks, forward observation-gap auditing and a private-owner `/audit` command for the saved AAPL news lab.

The new `/audit` command is pending deployment. It reads one saved snapshot and replays recorded balances without requesting data or repairing state. It reports failed arithmetic/timing checks and recorded comparison gaps. It cannot independently certify corporate actions, complete session coverage or investment performance.

## Evidence

- Last code verification: 102 deployment and 139 research tests pass (241 total), recorded in TEST_CAMPAIGN_LATEST.json with source hashes.
- Historical campaign: 200 comparisons, 20 independently restarted periods, five policies, base/doubled modeled costs. Each active strategy beat the matched passive return in 3/20 periods. No candidate promoted.
- Forward audit: 72 bounded news-lab observations for 9 October; one 635.372-second candidate gap requires persisted-ledger review.
- Railway point-in-time check on 11 October: one running worker, SUCCESS deployment and no recent failures in the default eight-hour status window. This is not continuous uptime certification.

No verified profit, customer revenue or time-savings figure is claimed. Software fixture tests establish checked behavior, not a profitable edge. Historical adjusted prices still need independent verification. Full persisted production ledgers have not been retrieved in this review.
